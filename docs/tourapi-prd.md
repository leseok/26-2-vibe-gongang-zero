# 공강제로 제품 요구사항

숭실대학교 학생이 앱을 연 날의 공강 시작·종료 시각을 입력하면, 그 시간에 열리는 문화행사와 문화·여가시설을 찾아준다. 검색 날짜는 한국시간 기준으로 자동 설정한다.

| 단계 | 요구사항 |
| --- | --- |
| [1단계 공강 시간 입력](../PRD_step1.md) | 학교와 오늘 날짜를 표시하고, 학생이 입력한 시작·종료 시각으로 공강 길이를 계산한다. |
| [2단계 주변 활동 추천](../PRD_step2.md) | TourAPI에서 동작구·관악구·서초구·영등포구·용산구·강남구의 행사와 시설을 조회하고 공강 시간으로 추린다. |
| [3단계 서울 전체 검색](../PRD_step3.md) | 여섯 구의 조회를 정상적으로 마쳤으며 추천 결과가 0건이면 같은 조건으로 서울 전체를 조회한다. 장소, 일정 및 공식 안내 링크를 제공한다. |

이번 작업은 2·3단계의 TourAPI 조회와 추천 로직을 담당한다. API 연결과 응답 형식은 [README](../README.md)를 참고한다. 영화관 상영 일정은 3단계 PRD의 후속 기능 항목에 정리한다.

팀의 활동 코스와 친구 모임 기획은 [팀 PRD](../PRD.md)에 있다.
