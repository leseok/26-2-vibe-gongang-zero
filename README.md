# 공강 제로 (Gongang Zero)

공강 시간에 즐길 수 있는 전시, 팝업, 공연·축제, 영화를 숭실대학교 주변과 서울에서 찾는 대학생용 웹앱입니다. 바이브 코딩을 활용해 개발하는 8조 팀 프로젝트입니다.

## 만들게 된 이유

전시, 공연, 영화 정보가 여러 곳에 흩어져 있어 공강에 무엇을 할지 정하는 데 시간이 걸립니다. 공강 제로는 서울의 문화 활동을 한곳에 모아, 다음 수업 전 여유 시간에 맞는 후보를 쉽게 찾도록 돕습니다.

## 현재 기능

- **문화 활동 탐색** — 숭실대가 있는 동작구부터 서울 전역까지 전시, 팝업, 공연·축제를 조회합니다. 영화 메뉴에서는 최근 일별 박스오피스를 볼 수 있습니다.
- **공강 조건으로 검색** — 날짜, 공강 시작·종료 시간, 지역, 예산을 지정하고 유형 또는 무료 여부로 결과를 좁힙니다. 운영시간이나 관람 소요 시간이 확인되는 경우 공강 시간과 비교합니다.
- **상세 정보 확인** — 장소, 기간, 이용 요금과 제공되는 공식 링크를 확인합니다. 영화 카드는 집계일과 러닝타임을 표시하고, KOBIS 작품 정보와 극장 시간표에 연결합니다.
- **관심 활동 저장** — 카드의 북마크로 저장한 뒤 **저장한 활동** 메뉴에서 다시 확인합니다.

이동·관람·학교 복귀 시간을 고려한 코스 안내와 친구 일정 조율은 확장 기능으로 검토하고 있습니다.

## 기술 스택 및 개발 상태

프론트엔드는 순수 HTML·CSS·JavaScript입니다. Vercel의 Node.js 서버리스 함수가 TourAPI와 KOBIS를 호출하고 화면에 필요한 형태로 변환합니다. 패키지 설치와 프론트엔드 빌드 없이 로컬에서 실행할 수 있습니다.

현재 API 연동 코드, 검색 필터, 카드, 관심 활동 저장이 구현되어 있습니다. 실제 행사 목록은 조회일과 제공처 데이터에 따라 달라집니다.

| 데이터 | 환경변수 | 제공처 |
| --- | --- | --- |
| 서울의 문화행사 및 운영시간·요금 | `TOUR_API_KEY` | [한국관광공사 국문 관광정보 서비스](https://www.data.go.kr/data/15101578/openapi.do) |
| 최근 박스오피스, 영화 장르와 러닝타임 | `KOBIS_API_KEY` | [영화진흥위원회 KOBIS Open API](https://www.kobis.or.kr/kobisopenapi/homepg/main/main.do) |

## 로컬에서 실행하기

1. Node.js 22 이상을 설치하고 `server.mjs`가 있는 폴더에서 터미널을 엽니다.
2. PowerShell에서 환경변수 양식을 복사해 메모장으로 엽니다. 이미 `.env.local`이 있으면 메모장 명령만 실행합니다.

   ```powershell
   Copy-Item .env.example .env.local
   notepad .env.local
   ```

3. 등호 오른쪽에 발급받은 값을 입력합니다. 키가 한 개면 해당 출처부터 볼 수 있습니다.

   ```dotenv
   TOUR_API_KEY=
   KOBIS_API_KEY=
   ```

4. `node server.mjs`를 실행하고 브라우저에서 [공강 제로 로컬 화면](http://127.0.0.1:3000)을 엽니다. 값을 수정한 뒤에는 Ctrl+C로 서버를 종료하고 다시 실행합니다.

## 브라우저에서 확인하기

| 확인할 동작 | 입력과 기대 결과 |
| --- | --- |
| 행사 조회 | **문화행사**에서 오늘, 서울 전체, 예산 제한 없음, 09:00~22:00을 선택합니다. 조회 중 표시가 끝나고 해당 날짜 행사 카드 또는 빈 결과가 나타납니다. |
| 날짜·지역 | 위 조건에서 날짜를 바꾸고 **맞춤 활동 찾기**를 누릅니다. 결과가 새 날짜로 바뀝니다. **숭실대가 있는 동작구에서 찾기**를 누르면 동작구 행사만 표시됩니다. |
| 무료 필터 | **무료만 보기**를 체크합니다. 무료로 확인된 행사만 남고, 가격 미확인 항목은 목록에서 빠집니다. |
| 정보 누락 | 무료 필터와 예산 제한을 풀고 가격·시간이 제공되지 않은 카드에서 **가격 미확인**, **시간 확인**을 확인합니다. 실제 조회 결과에 해당 항목이 있을 때 확인할 수 있습니다. |
| 결과 없음과 실패 | 결과가 없는 지역·날짜 조합은 **조건에 맞는 활동이 없어요**로 표시됩니다. API 호출 실패 시 **연결 오류**와 **다시 조회**가 표시됩니다. |
| 영화 상세와 저장 | 영화 카드의 **KOBIS 영화 정보**를 누르면 해당 작품 페이지가 열립니다. 북마크를 누른 뒤 **저장한 활동**에서 같은 카드를 찾을 수 있습니다. |

## Vercel에 배포하기

1. 프로젝트를 GitHub 저장소에 올립니다. 실제 키가 들어 있는 `.env.local`은 로컬에 보관합니다.
2. Vercel에서 프로젝트를 가져옵니다. **Root Directory**는 `vercel.json`이 있는 폴더, **Framework Preset**은 **Other**로 지정합니다. 출력 폴더 `public/`은 설정 파일에 지정되어 있습니다.
3. **Environment Variables**에 `TOUR_API_KEY`와 `KOBIS_API_KEY`를 추가한 다음 배포합니다. 이미 배포한 프로젝트에서 키를 수정했다면 다시 배포해 적용합니다.

## 파일 구성

| 경로 | 역할 |
| --- | --- |
| `AGENTS.md` | 개발 범위와 검증 기준 |
| `public/index.html`, `public/style.css` | 메인 화면과 반응형 스타일 |
| `public/script.js`, `public/data.js` | API 요청, 카드 표시, 검색·저장, 서울 지역과 필터 규칙 |
| `api/events.js`, `api/movies.js` | Vercel 서버리스 함수 진입점 |
| `lib/activity-api.mjs` | 외부 데이터 조회 및 공통 응답 변환 |
| `server.mjs`, `vercel.json` | 로컬 실행 서버와 Vercel 설정 |
| `.env.example` | 로컬 환경변수 양식 |
