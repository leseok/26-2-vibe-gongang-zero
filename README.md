# 공강 제로 (Gongang Zero)

공강에 즐길 수 있는 전시, 팝업, 공연·축제, 영화를 학교 근처에서 찾는 대학생용 웹앱입니다. 바이브 코딩을 활용해 개발하는 8조 팀 프로젝트입니다.

## 만들게 된 이유

전시, 공연, 영화 정보가 여러 곳에 흩어져 있어 공강에 뭘 할지 정하는 데 시간이 걸립니다. 공강 제로는 숭실대학교 주변과 서울의 문화 활동을 한곳에서 보고, 공강 시간에 맞는 행사를 쉽게 찾도록 돕습니다.

## 구현 예정 기능

- **주변 문화 활동 찾기** — 실제 API에서 가져온 전시, 팝업, 공연·축제, 영화 정보를 카드로 보여줍니다.
- **공강 조건으로 검색** — 날짜, 공강 시간, 지역을 선택하고 행사 종류 또는 무료 여부로 결과를 좁힙니다.
- **상세 정보 확인** — 행사 장소, 일정, 가격과 공식 상세 정보를 확인합니다. 영화는 제공되는 상영 정보나 상세 정보 링크를 보여줍니다.
- **관심 활동 저장** — 마음에 드는 활동을 저장해 다시 볼 수 있습니다.

## 기술 스택 및 개발 상태

프론트엔드는 순수 HTML·CSS·JavaScript를 사용합니다. 외부 행사 데이터는 Node.js 기반 Vercel 서버리스 함수로 가져옵니다. 현재 기획 단계이며, 데이터 제공처와 로컬 실행 방법은 API 연동 후 추가합니다.
