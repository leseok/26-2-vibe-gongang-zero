# 공강 제로 (Gongang Zero)

공강 시간에 맞춰 학교 근처의 전시, 팝업, 공연 같은 문화 행사를 추천하는 대학생용 앱입니다. 바이브 코딩을 활용해 개발하는 8조 팀 프로젝트입니다.

## 만들게 된 이유

공강에 가볼 만한 곳을 찾으려면 여러 곳에서 행사 정보를 확인하고, 다음 수업 전까지 돌아올 수 있는지 직접 계산해야 합니다. 공강 제로는 주변 행사 정보와 왕복 이동 시간을 한곳에서 보여줘, 주어진 시간에 실제로 다녀올 수 있는 활동을 찾기 쉽게 만드는 것이 목표입니다.

## 구현 예정 기능

- **주변 행사 추천** — 학교 또는 출발 위치와 공강 시간을 기준으로 전시, 팝업, 공연을 추천합니다.
- **조건에 맞는 행사 탐색** — 관심 분야와 예산에 맞춰 추천 목록을 좁히고, 행사 시간과 위치를 확인합니다.
- **공강에 맞는 코스 안내** — 이동과 관람, 학교 복귀에 걸리는 시간을 함께 고려해 다음 수업 전에 다녀올 수 있는 코스를 보여줍니다.
- **친구와 일정 정하기** — 확장 기능으로 친구들의 가능한 시간과 선호를 모아 코스 후보를 제안하고 투표로 정할 수 있도록 합니다.

## 개발 상태

현재 기획 단계입니다. 기술 스택과 행사 데이터 출처가 정해지고 앱을 실행할 수 있게 되면, 이 문서에 설치 및 실행 방법을 추가합니다.
